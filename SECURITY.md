# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

**Do NOT open a public GitHub issue for security vulnerabilities.**

Instead, please email: **security@bnbchain.org**

Include:

- A description of the vulnerability
- Steps to reproduce the issue
- Potential impact
- Suggested fix (if any)

## Response Timeline

- **Acknowledgement:** Within 48 hours of receiving your report.
- **Assessment:** Within 5 business days we will assess the severity and confirm the vulnerability.
- **Fix:** We aim to release a patch within 14 days for critical issues.

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |

## Scope

This policy applies to the token-recover-self-service-tools repository. For vulnerabilities in the BNB Chain protocol or smart contracts, please refer to the [BNB Chain Bug Bounty Program](https://bugbounty.bnbchain.org/).
